## Código abierto

El proyecto es **open source** y su código está disponible en GitHub:

> [github.com/candidojesusgarciagarcia/Portafolio-Candido-Jesus-Garcia-Garcia](https://github.com/candidojesusgarciagarcia/Portafolio-Candido-Jesus-Garcia-Garcia)

Para trabajar con él localmente, clona el repositorio e instala las dependencias:

```bash
git clone https://github.com/candidojesusgarciagarcia/Portafolio-Candido-Jesus-Garcia-Garcia.git
cd Portafolio-Candido-Jesus-Garcia-Garcia/portafolio-candidojesusgarciagarcia
pnpm install
pnpm dev
```

Vite mostrará en la terminal la dirección local para abrir el proyecto durante el desarrollo.

## Versión compilada

La versión lista para publicar se genera en:

```text
portafolio-candidojesusgarciagarcia/dist/index.html
```

Para crearla desde el código fuente:

```bash
cd portafolio-candidojesusgarciagarcia
pnpm build
```

Después, abre `dist/index.html` en tu navegador. También puedes previsualizarla con un servidor local:

```bash
pnpm preview
```

> La carpeta `dist` contiene los archivos estáticos preparados para desplegarse en cualquier hosting web. En este proyecto, la compilación integra la aplicación en un único `index.html`, junto con los recursos públicos necesarios.
